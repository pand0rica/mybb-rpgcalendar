# Holiday icon

Default marker shown in front of every holiday entry. `calendar-star.svg` is the
plugin's own icon, drawn in the same visual language as the bundled weather set
(`../weather`, Meteocons style): a 512×512 filled SVG with soft gradients — a light
calendar sheet with a magenta header (matching the holiday chip accent `#ec4899`)
and a golden star (matching the amber sun palette).

The *Holiday symbol* setting (`rpgcalendar_holiday_symbol`) points here by default.
Drop your own image in this folder (or set the setting to another URL / an emoji /
short text) to replace it.
