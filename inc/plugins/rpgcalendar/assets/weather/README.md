# Weather icons

Default weather icon set shipped with rpgcalendar. One image per WMO weather code
(plus `windy.svg`), so the calendar shows a matching picture for each generated or
manually chosen weather condition. Files are named after the WMO code
(`0.svg` … `99.svg`) and `windy.svg`; drop your own images here (or point the
*Weather image directory* setting elsewhere) to replace them. Per-code variants are
possible with a dash suffix, e.g. `61-1.svg`, `61-night.svg`.
